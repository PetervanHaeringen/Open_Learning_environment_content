당신은 이제 구성 요소들을 다 알고 있습니다. 이제 무언가를 직접 만들어 볼 차례입니다.

이 모듈에서는 네 가지 프로젝트 중 하나를 골라서 끝까지 완성해 봅니다. 완벽할 필요는 없습니다 — 다만 작동해야 합니다. 그리고 "작동한다"는 것이야말로 유일하게 의미 있는 기준입니다.

### 프로젝트 A — 퀴즈

질문을 던지고 몇 개나 맞혔는지 기록하는 퀴즈입니다.

**하는 일:**
- 3개 이상의 질문을 던진다
- 사용자로부터 답변을 받는다
- 정답인지 오답인지 알려준다
- 마지막에 총점을 준다

**시작 코드:**
```javascript
let 점수 = 0;

function 질문하기(질문, 정답) {
    let 답변 = prompt(질문);
    if (답변.toLowerCase() === 정답.toLowerCase()) {
        alert("정답입니다!");
        점수++;
    } else {
        alert("아쉽네요. 정답은: " + 정답);
    }
}

질문하기("네덜란드의 수도는 어디인가요?", "Amsterdam");
질문하기("7 곱하기 8은 얼마인가요?", "56");
질문하기("기계를 위한 최초의 알고리즘을 쓴 사람은 누구인가요?", "Ada Lovelace");

alert("당신의 점수: 3점 만점에 " + 점수 + "점");
```

**확장해 보기:**
- 질문을 더 추가하기
- 문제마다 피드백 주기
- `Math.random()`을 사용해 질문 순서를 무작위로 만들기

### 프로젝트 B — 계산기

두 숫자와 연산자로 계산하는 계산기입니다.

**하는 일:**
- 숫자 두 개를 묻는다
- 어떤 연산인지 묻는다 (+, -, *, /)
- 결과를 준다

**시작 코드:**
```javascript
function 계산하기(a, b, 연산자) {
    if (연산자 === "+") return a + b;
    if (연산자 === "-") return a - b;
    if (연산자 === "*") return a * b;
    if (연산자 === "/") {
        if (b === 0) return "0으로 나눌 수 없습니다";
        return a / b;
    }
    return "알 수 없는 연산자입니다";
}

let 숫자1 = Number(prompt("첫 번째 숫자:"));
let 숫자2 = Number(prompt("두 번째 숫자:"));
let 연산자 = prompt("연산자 (+, -, *, /):");

let 결과 = 계산하기(숫자1, 숫자2, 연산자);
alert(숫자1 + " " + 연산자 + " " + 숫자2 + " = " + 결과);
```

**확장해 보기:**
- 사용자가 연속으로 여러 번 계산할 수 있게 하기
- 제곱근 기능 추가하기 (`Math.sqrt()`)
- 모든 계산 기록을 저장하기

### 프로젝트 C — 텍스트 처리기

당신이 입력한 텍스트에 무언가를 하는 프로그램입니다.

**하는 일:**
- 텍스트 안의 단어 수를 센다
- 특정 단어가 몇 번 나오는지 센다
- 텍스트를 대문자 또는 소문자로 변환한다

**시작 코드:**
```javascript
let 텍스트 = prompt("텍스트를 입력하세요:");

let 단어목록 = 텍스트.split(" ");
alert("단어 수: " + 단어목록.length);

let 검색어 = prompt("어떤 단어를 찾고 싶으세요?");
let 개수 = 0;
for (let i = 0; i < 단어목록.length; i++) {
    if (단어목록[i].toLowerCase() === 검색어.toLowerCase()) {
        개수++;
    }
}
alert("'" + 검색어 + "'는(은) " + 개수 + "번 나타납니다");
```

**확장해 보기:**
- 한 단어를 다른 단어로 바꾸기
- 단어의 순서를 뒤집기
- 문장의 개수 세기 (힌트: 마침표를 찾아보세요)

### 프로젝트 D — 숫자 맞히기

컴퓨터가 숫자를 고르고, 당신이 그것을 맞혀야 하는 게임입니다.

**하는 일:**
- 컴퓨터가 1부터 100 사이의 무작위 숫자를 고른다
- 플레이어가 추측한다
- 프로그램이 "너무 높음", "너무 낮음", 또는 "정답"이라고 알려준다
- 플레이어가 몇 번 시도했는지 센다

**시작 코드:**
```javascript
let 비밀숫자 = Math.floor(Math.random() * 100) + 1;
let 시도횟수 = 0;
let 맞췄는가 = false;

while (!맞췄는가) {
    let 추측 = Number(prompt("1부터 100 사이의 숫자를 맞혀보세요:"));
    시도횟수++;

    if (추측 < 비밀숫자) {
        alert("너무 낮아요! 더 큰 숫자를 시도해보세요.");
    } else if (추측 > 비밀숫자) {
        alert("너무 높아요! 더 작은 숫자를 시도해보세요.");
    } else {
        alert("정답입니다! " + 시도횟수 + "번 만에 맞히셨네요.");
        맞췄는가 = true;
    }
}
```

**확장해 보기:**
- 최대 시도 횟수 추가하기
- 시도 횟수에 따라 등급 매기기
- 페이지를 새로고침하지 않고도 다시 플레이할 수 있게 하기

## 이것을 어떻게 접근할까

**1단계 — 선택하고 시작 코드를 이해하라**
코드를 한 줄씩 읽어보세요. 각 줄이 무엇을 하는지 설명할 수 있나요?

**2단계 — 있는 그대로 작동하게 만들어라**
시작 코드를 브라우저 콘솔에 복사하고 실행해 보세요. 작동하나요?

**3단계 — 한 가지만 조정하라**
작은 값 하나를 바꾸거나 한 줄을 추가하세요. 다시 실행해 보세요.

**4단계 — 한 단계씩 확장하라**
한 번에 하나씩 확장 기능을 추가하세요. 추가할 때마다 테스트하세요.

**5단계 — 일부러 고장 내보라**
무언가를 바꿔서 실패하게 만들어 보세요. 오류 메시지를 읽으세요. 고치세요.

## 좋은 프로그램이란 무엇인가?

- 해야 할 일을 해낸다

- 예상치 못한 입력에도 멈추지 않는다
- 어떻게 작동하는지 다른 사람에게 설명할 수 있다
