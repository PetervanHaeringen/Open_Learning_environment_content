# الوحدة 8 — بناء شيء حقيقي

أنت تعرف اللبنات الأساسية. الآن ستبني شيئًا فعليًا.

في هذه الوحدة، تختار واحدًا من أربعة مشاريع وتُنجزه. ليس بالضرورة مثاليًا — لكن يجب أن يعمل. والعمل هو المقياس الوحيد الذي يهم فعلًا.

---

## اختر مشروعك

اختر المشروع الذي يستهويك أكثر.

---

### المشروع أ — اختبار قصير (Quiz)

اختبار يطرح أسئلة ويتتبع عدد إجاباتك الصحيحة.

**ما الذي يفعله:**
- يطرح 3 أسئلة أو أكثر
- يستقبل إجابة من المستخدم
- يخبرك ما إذا كانت صحيحة أم خاطئة
- يعطي المجموع النهائي في النهاية

**نقطة البداية:**
```javascript
let النتيجة = 0;

function اطرحسؤالا(السؤال, الإجابةالصحيحة) {
    let الإجابة = prompt(السؤال);
    if (الإجابة.toLowerCase() === الإجابةالصحيحة.toLowerCase()) {
        alert("صحيح!");
        النتيجة++;
    } else {
        alert("للأسف. الإجابة الصحيحة كانت: " + الإجابةالصحيحة);
    }
}

اطرحسؤالا("ما هي عاصمة هولندا؟", "Amsterdam");
اطرحسؤالا("كم يساوي 7 × 8؟", "56");
اطرحسؤالا("من كتب أول خوارزمية لآلة؟", "Ada Lovelace");

alert("نتيجتك: " + النتيجة + " من أصل 3");
```

**التوسيع:**
- أضِف المزيد من الأسئلة
- أعطِ ملاحظات لكل سؤال
- اجعل ترتيب الأسئلة عشوائيًا باستخدام `Math.random()`

---

### المشروع ب — آلة حاسبة

آلة حاسبة تحسب باستخدام رقمين وعملية حسابية.

**ما الذي تفعله:**
- تطلب رقمين
- تسأل عن العملية (+، -، *، /)
- تعطي النتيجة

**نقطة البداية:**
```javascript
function احسب(a, b, العملية) {
    if (العملية === "+") return a + b;
    if (العملية === "-") return a - b;
    if (العملية === "*") return a * b;
    if (العملية === "/") {
        if (b === 0) return "لا يمكن القسمة على صفر";
        return a / b;
    }
    return "عملية غير معروفة";
}

let الرقم1 = Number(prompt("الرقم الأول:"));
let الرقم2 = Number(prompt("الرقم الثاني:"));
let العملية = prompt("العملية (+، -، *، /):");

let النتيجة = احسب(الرقم1, الرقم2, العملية);
alert(الرقم1 + " " + العملية + " " + الرقم2 + " = " + النتيجة);
```

**التوسيع:**
- اترك للمستخدم إجراء عدة حسابات متتالية
- أضِف الجذر التربيعي (`Math.sqrt()`)
- احفظ سجلًا لجميع العمليات الحسابية

### المشروع ج — معالج نصوص

برنامج يقوم بشيء ما بالنص الذي تُدخله.

**ما الذي يفعله:**
- يحسب عدد الكلمات في نص ما
- يحسب عدد مرات ظهور كلمة معيّنة
- يحوّل النص إلى أحرف كبيرة أو صغيرة

**نقطة البداية:**
```javascript
let النص = prompt("أدخل نصًا:");

let الكلمات = النص.split(" ");
alert("عدد الكلمات: " + الكلمات.length);

let كلمةالبحث = prompt("ما الكلمة التي تريد البحث عنها؟");
let العداد = 0;
for (let i = 0; i < الكلمات.length; i++) {
    if (الكلمات[i].toLowerCase() === كلمةالبحث.toLowerCase()) {
        العداد++;
    }
}
alert("'" + كلمةالبحث + "' تظهر " + العداد + " مرة");
```

**التوسيع:**
- استبدل كلمة بكلمة أخرى
- اعكس ترتيب الكلمات
- احسب عدد الجمل (تلميح: ابحث عن النقاط)

### المشروع د — خمّن الرقم

لعبة يختار فيها الحاسوب رقمًا وعليك أن تخمّنه.

**ما الذي تفعله:**
- يختار الحاسوب رقمًا عشوائيًا بين 1 و100
- يخمّن اللاعب
- يقول البرنامج "مرتفع جدًا" أو "منخفض جدًا" أو "تخمين صحيح"
- يحسب عدد المحاولات التي احتاجها اللاعب

**نقطة البداية:**
```javascript
let السر = Math.floor(Math.random() * 100) + 1;
let المحاولات = 0;
let تمالتخمين = false;

while (!تمالتخمين) {
    let التخمين = Number(prompt("خمّن رقمًا بين 1 و100:"));
    المحاولات++;

    if (التخمين < السر) {
        alert("منخفض جدًا! جرّب رقمًا أعلى.");
    } else if (التخمين > السر) {
        alert("مرتفع جدًا! جرّب رقمًا أقل.");
    } else {
        alert("تخمين صحيح! احتجت إلى " + المحاولات + " محاولة.");
        تمالتخمين = true;
    }
}
```

**التوسيع:**
- أضِف حدًا أقصى لعدد المحاولات
- أعطِ تقييمًا بناءً على عدد المحاولات
- اترك للاعب إمكانية اللعب مجددًا دون إعادة تحميل الصفحة

## كيف تتعامل مع هذا

**الخطوة 1 — اختر وافهم نقطة البداية**
اقرأ الكود سطرًا بسطر. هل يمكنك شرح ما يفعله كل سطر؟

**الخطوة 2 — اجعله يعمل كما هو**
انسخ نقطة البداية إلى طرفية المتصفح ونفّذها. هل تعمل؟

**الخطوة 3 — عدّل شيئًا واحدًا**
غيّر قيمة صغيرة واحدة أو أضِف سطرًا واحدًا. نفّذها مجددًا.

**الخطوة 4 — وسّع خطوة بخطوة**
أضِف توسيعًا واحدًا في كل مرة. اختبر بعد كل إضافة.

**الخطوة 5 — اكسره عن قصد**
غيّر شيئًا يجعله يفشل. اقرأ رسالة الخطأ. أصلحه.

---

## ما الذي يجعل برنامجًا جيدًا؟

- يفعل ما يُفترض أن يفعله
- يعطي ملاحظات واضحة للمستخدم
- لا يتعطل عند إدخال غير متوقّع
- يمكنك أن تشرح للآخرين كيف يعمل

الكمالية هي عدوّ الإنجاز. اجعله يعمل أولًا — ثم يمكنك تحسينه.
