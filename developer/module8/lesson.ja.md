# モジュール8 — 本物のものを作る

あなたはもう、構成要素をすべて知っています。今度は、何かを実際に作ってみましょう。

このモジュールでは、4つのプロジェクトの中からひとつを選び、それを最後まで仕上げます。完璧である必要はありません——ただし、動くものにしてください。そして「動くこと」こそが、唯一意味のある基準です。

---

## プロジェクトを選ぶ

一番心が惹かれるプロジェクトを選んでください。

---

### プロジェクトA — クイズ

質問を出し、何問正解したかを記録するクイズです。

**このプログラムがすること：**
- 3問以上の質問をする
- ユーザーの回答を受け取る
- それが正解か不正解かを伝える
- 最後に合計得点を表示する

**出発点となるコード：**
```javascript
let スコア = 0;

function 質問する(質問文, 正解) {
    let 回答 = prompt(質問文);
    if (回答.toLowerCase() === 正解.toLowerCase()) {
        alert("正解！");
        スコア++;
    } else {
        alert("残念。正解は: " + 正解);
    }
}

質問する("オランダの首都はどこ？", "Amsterdam");
質問する("7かける8はいくつ？", "56");
質問する("機械のための最初のアルゴリズムを書いたのは誰？", "Ada Lovelace");

alert("あなたのスコア: 3問中 " + スコア + "問正解");
```

**拡張してみよう：**
- 質問をもっと追加する
- 各問題ごとにフィードバックを出す
- `Math.random()` を使って質問の順番をランダムにする

---

### プロジェクトB — 電卓

2つの数値と演算を使って計算する電卓です。

**このプログラムがすること：**
- 2つの数値を尋ねる
- どの演算をするか尋ねる（+、-、*、/）
- 結果を返す

**出発点となるコード：**
```javascript
function 計算する(a, b, 演算子) {
    if (演算子 === "+") return a + b;
    if (演算子 === "-") return a - b;
    if (演算子 === "*") return a * b;
    if (演算子 === "/") {
        if (b === 0) return "ゼロで割ることはできません";
        return a / b;
    }
    return "不明な演算子です";
}

let 数値1 = Number(prompt("最初の数値："));
let 数値2 = Number(prompt("2番目の数値："));
let 演算子 = prompt("演算子 (+, -, *, /)：");

let 結果 = 計算する(数値1, 数値2, 演算子);
alert(数値1 + " " + 演算子 + " " + 数値2 + " = " + 結果);
```

**拡張してみよう：**
- ユーザーが連続して複数回計算できるようにする
- 平方根を追加する（`Math.sqrt()`）
- すべての計算履歴を保存する

### プロジェクトC — テキスト処理プログラム

入力したテキストに対して何かを行うプログラムです。

**このプログラムがすること：**
- テキストの単語数を数える
- 特定の単語が何回出現するかを数える
- テキストを大文字または小文字に変換する

**出発点となるコード：**
```javascript
let テキスト = prompt("テキストを入力してください：");

let 単語一覧 = テキスト.split(" ");
alert("単語数: " + 単語一覧.length);

let 検索語 = prompt("どの単語を探しますか？");
let カウント = 0;
for (let i = 0; i < 単語一覧.length; i++) {
    if (単語一覧[i].toLowerCase() === 検索語.toLowerCase()) {
        カウント++;
    }
}
alert("「" + 検索語 + "」は " + カウント + " 回出現します");
```

**拡張してみよう：**
- ある単語を別の単語に置き換える
- 単語の並び順を逆にする
- 文の数を数える（ヒント：ピリオドを探す）

---

### プロジェクトD — 数当てゲーム

コンピューターが選んだ数を、あなたが当てるゲームです。

**このプログラムがすること：**
- コンピューターが1から100の間でランダムに数を選ぶ
- プレイヤーが予想する
- プログラムは「大きすぎる」「小さすぎる」「正解」のいずれかを伝える
- プレイヤーが何回で当てられたかを数える

**出発点となるコード：**
```javascript
let 正解の数 = Math.floor(Math.random() * 100) + 1;
let 試行回数 = 0;
let 正解した = false;

while (!正解した) {
    let 予想 = Number(prompt("1から100の間の数を当ててください："));
    試行回数++;

    if (予想 < 正解の数) {
        alert("小さすぎます！もっと大きい数を試してください。");
    } else if (予想 > 正解の数) {
        alert("大きすぎます！もっと小さい数を試してください。");
    } else {
        alert("正解です！" + 試行回数 + "回かかりました。");
        正解した = true;
    }
}
```

**拡張してみよう：**
- 最大試行回数を設定する
- 試行回数に応じた評価を出す
- ページを再読み込みせずに、もう一度プレイできるようにする

## どう取り組めばいいか

**ステップ1——選んで、出発点となるコードを理解する**
コードを1行ずつ読んでみましょう。それぞれの行が何をしているか、説明できますか？

**ステップ2——まずはそのまま動かしてみる**
出発点となるコードをブラウザのコンソールにコピーして実行してみましょう。動きますか？

**ステップ3——ひとつだけ変えてみる**
小さな値をひとつ変えるか、1行追加してみましょう。もう一度実行します。

**ステップ4——少しずつ拡張していく**
一度にひとつの拡張だけを追加しましょう。追加するたびにテストします。

**ステップ5——わざと壊してみる**
何かを変更して、失敗するようにしてみましょう。エラーメッセージを読みます。そして直します。

## 良いプログラムとは何か？

- それがすべきことを、ちゃんと行う
- ユーザーに明確なフィードバックを与える
- 予期しない入力があっても、クラッシュしない
- どう動いているかを、他の人に説明できる

完璧主義は、完成の敵です。まずは動くものを作りましょう——それから、改善していけばいいのです。
