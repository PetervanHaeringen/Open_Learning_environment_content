# 模块8 — 打造一个真正的东西

你已经掌握了这些构建模块。现在，你要动手打造点什么了。

在这个模块中，你要从四个项目中选择一个，并把它完成。不需要完美——但必须能跑起来。而"能跑起来"，是唯一真正重要的标准。

## 选择你的项目

选一个最吸引你的项目。

### 项目A — 小测验（Quiz）

一个会提问、并统计你答对了多少题的小测验。

**它要做到：**
- 至少提出3个问题
- 接收用户的回答
- 告诉你答对了还是答错了
- 最后给出总分

**起始代码：**
```javascript
let 分数 = 0;

function 提问(问题, 正确答案) {
    let 回答 = prompt(问题);
    if (回答.toLowerCase() === 正确答案.toLowerCase()) {
        alert("答对了！");
        分数++;
    } else {
        alert("很遗憾。正确答案是：" + 正确答案);
    }
}

提问("荷兰的首都是哪里？", "Amsterdam");
提问("7乘以8等于多少？", "56");
提问("谁为一台机器写下了第一个算法？", "Ada Lovelace");

alert("你的得分：" + 分数 + " / 3");
```

**扩展方向：**
- 增加更多问题
- 对每道题都给出反馈
- 用`Math.random()`让问题顺序变得随机

### 项目B — 计算器

一个可以对两个数字进行某种运算的计算器。

**它要做到：**
- 询问两个数字
- 询问要进行哪种运算（+、-、*、/）
- 给出结果

**起始代码：**
```javascript
function 计算(a, b, 运算符) {
    if (运算符 === "+") return a + b;
    if (运算符 === "-") return a - b;
    if (运算符 === "*") return a * b;
    if (运算符 === "/") {
        if (b === 0) return "不能除以零";
        return a / b;
    }
    return "未知的运算符";
}

let 数字1 = Number(prompt("第一个数字："));
let 数字2 = Number(prompt("第二个数字："));
let 运算符 = prompt("运算符 (+, -, *, /)：");

let 结果 = 计算(数字1, 数字2, 运算符);
alert(数字1 + " " + 运算符 + " " + 数字2 + " = " + 结果);
```

**扩展方向：**
- 让用户可以连续进行多次计算
- 加入开平方根功能（`Math.sqrt()`）
- 保存一份所有计算记录的历史

### 项目C — 文本处理器

一个能对你输入的文本做一些处理的程序。

**它要做到：**
- 统计一段文本中的单词数量
- 统计某个特定单词出现的次数
- 把文本转换成大写或小写

**起始代码：**
```javascript
let 文本 = prompt("请输入一段文本：");

let 单词列表 = 文本.split(" ");
alert("单词数量：" + 单词列表.length);

let 搜索词 = prompt("你想搜索哪个单词？");
let 计数 = 0;
for (let i = 0; i < 单词列表.length; i++) {
    if (单词列表[i].toLowerCase() === 搜索词.toLowerCase()) {
        计数++;
    }
}
alert("'" + 搜索词 + "' 出现了 " + 计数 + " 次");
```

**扩展方向：**
- 把某个单词替换成另一个单词
- 把单词的顺序反过来
- 统计句子的数量（提示：找找句号）

### 项目D — 猜数字

一个由计算机选一个数字、你来猜的游戏。

**它要做到：**
- 计算机随机选一个1到100之间的数字
- 玩家进行猜测
- 程序会提示"太高了"、"太低了"或"猜对了"
- 统计玩家一共猜了多少次

**起始代码：**
```javascript
let 秘密数字 = Math.floor(Math.random() * 100) + 1;
let 尝试次数 = 0;
let 已猜中 = false;

while (!已猜中) {
    let 猜测 = Number(prompt("请猜一个1到100之间的数字："));
    尝试次数++;

    if (猜测 < 秘密数字) {
        alert("太低了！再猜大一点。");
    } else if (猜测 > 秘密数字) {
        alert("太高了！再猜小一点。");
    } else {
        alert("猜对了！你一共用了 " + 尝试次数 + " 次。");
        已猜中 = true;
    }
}
```

**扩展方向：**
- 加入最大尝试次数的限制
- 根据尝试次数给出一个评价
- 让玩家不用刷新页面就能再玩一次

## 该怎么下手

**第一步——选一个项目，理解起始代码**
逐行阅读代码。你能解释清楚每一行在做什么吗？

**第二步——先让它原样跑起来**
把起始代码复制到浏览器控制台里运行。它能正常工作吗？

**第三步——只改动一处**
改一个小小的值，或者加一行代码。再运行一次。

**第四步——一步一步地扩展**
每次只加一个扩展功能。每加一个，就测试一次。

**第五步——故意把它弄坏**
改一些东西，让它出错。读懂错误信息。然后修好它。

---

## 什么才算是一个好程序？

- 它做到了它该做的事
- 它给用户清晰的反馈
- 遇到意外的输入，它不会崩溃
- 你能向别人解释清楚它是怎么运作的

完美主义，是"完成"的敌人。先让它能跑起来——然后你才能去把它改得更好。
