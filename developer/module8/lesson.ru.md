### Проект А — Викторина

Викторина, которая задаёт вопросы и отслеживает, сколько раз вы ответили правильно.

**Что она делает:**
- Задаёт 3 или больше вопросов
- Принимает ответ от пользователя
- Сообщает, правильный он или нет
- В конце выдаёт общий результат

**Отправная точка:**
```javascript
let счёт = 0;

function задатьВопрос(вопрос, правильныйОтвет) {
    let ответ = prompt(вопрос);
    if (ответ.toLowerCase() === правильныйОтвет.toLowerCase()) {
        alert("Правильно!");
        счёт++;
    } else {
        alert("Увы. Правильный ответ был: " + правильныйОтвет);
    }
}

задатьВопрос("Какая столица Нидерландов?", "Amsterdam");
задатьВопрос("Сколько будет 7 умножить на 8?", "56");
задатьВопрос("Кто написал первый алгоритм для машины?", "Ada Lovelace");

alert("Ваш результат: " + счёт + " из 3");
```

**Расширение:**
- Добавьте больше вопросов
- Дайте обратную связь по каждому вопросу
- Сделайте порядок вопросов случайным с помощью `Math.random()`

### Проект Б — Калькулятор

Калькулятор, который вычисляет результат с двумя числами и операцией.

**Что он делает:**
- Запрашивает два числа
- Спрашивает, какая операция (+, -, *, /)
- Выдаёт результат

**Отправная точка:**
```javascript
function вычислить(a, b, операция) {
    if (операция === "+") return a + b;
    if (операция === "-") return a - b;
    if (операция === "*") return a * b;
    if (операция === "/") {
        if (b === 0) return "Нельзя делить на ноль";
        return a / b;
    }
    return "Неизвестная операция";
}

let число1 = Number(prompt("Первое число:"));
let число2 = Number(prompt("Второе число:"));
let операция = prompt("Операция (+, -, *, /):");

let результат = вычислить(число1, число2, операция);
alert(число1 + " " + операция + " " + число2 + " = " + результат);
```

**Расширение:**
- Позвольте пользователю выполнять несколько вычислений подряд
- Добавьте квадратный корень (`Math.sqrt()`)
- Сохраняйте историю всех вычислений

### Проект В — Обработчик текста

Программа, которая что-то делает с текстом, который вы вводите.

**Что она делает:**
- Считает количество слов в тексте
- Считает, сколько раз встречается определённое слово
- Преобразует текст в верхний или нижний регистр

**Отправная точка:**
```javascript
let текст = prompt("Введите текст:");

let слова = текст.split(" ");
alert("Количество слов: " + слова.length);

let искомоеСлово = prompt("Какое слово вы хотите найти?");
let счётчик = 0;
for (let i = 0; i < слова.length; i++) {
    if (слова[i].toLowerCase() === искомоеСлово.toLowerCase()) {
        счётчик++;
    }
}
alert("'" + искомоеСлово + "' встречается " + счётчик + " раз(а)");
```

**Расширение:**
- Замените одно слово на другое
- Измените порядок слов на обратный
- Подсчитайте количество предложений (подсказка: ищите точки)

### Проект Г — Угадай число

Игра, в которой компьютер загадывает число, а вы должны его угадать.

**Что она делает:**
- Компьютер выбирает случайное число от 1 до 100
- Игрок делает предположение
- Программа говорит «слишком высоко», «слишком низко» или «угадал»
- Она считает, сколько попыток понадобилось игроку

**Отправная точка:**
```javascript
let секрет = Math.floor(Math.random() * 100) + 1;
let попытки = 0;
let угадано = false;

while (!угадано) {
    let догадка = Number(prompt("Угадайте число от 1 до 100:"));
    попытки++;

    if (догадка < секрет) {
        alert("Слишком низко! Попробуйте больше.");
    } else if (догадка > секрет) {
        alert("Слишком высоко! Попробуйте меньше.");
    } else {
        alert("Угадали! Вам понадобилось попыток: " + попытки);
        угадано = true;
    }
}
```

**Расширение:**
- Добавьте максимальное количество попыток
- Давайте оценку в зависимости от количества попыток
- Позвольте игроку сыграть снова без перезагрузки страницы

## Как к этому подойти

**Шаг 1 — Выберите и разберитесь в отправной точке**
Прочитайте код строчка за строчкой. Можете ли вы объяснить, что делает каждая строка?

**Шаг 2 — Заставьте это работать как есть**
Скопируйте отправную точку в консоль браузера и запустите. Работает ли это?

**Шаг 3 — Измените одну вещь**
Измените одно небольшое значение или добавьте одну строку. Запустите снова.

**Шаг 4 — Расширяйте шаг за шагом**
Добавляйте одно расширение за раз. Тестируйте после каждого добавления.

**Шаг 5 — Сломайте это намеренно**
Измените что-то так, чтобы это сломалось. Прочитайте сообщение об ошибке. Исправьте.

## Что делает программу хорошей?

- Она делает то, что должна делать
- Она даёт понятную обратную связь пользователю
- Она не падает при неожиданном вводе
- Вы можете объяснить другим, как она работает

Перфекционизм — враг завершённости. Сделайте, чтобы оно работало — а уже потом сможете это улучшить.
