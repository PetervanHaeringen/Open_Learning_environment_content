# الوحدة 4 — مقارنة اللغات

توجد مئات اللغات البرمجية. لست بحاجة لمعرفتها كلها.
لكن عليك أن تفهم لماذا يوجد هذا العدد الكبير منها — وكيف تختار من بينها.

## 1. نفس المشكلة، بثلاث لغات

لنبدأ بخوارزمية بسيطة: تحديد ما إذا كان رقم ما زوجيًا أم فرديًا.

**الكود الزائف (Pseudocode)** — ليست لغة حقيقية، مجرد كتابة الفكرة:
```
إذا كان الرقم قابلًا للقسمة على 2:
    اطبع "زوجي"
وإلا:
    اطبع "فردي"
```

**Python:**
```python
رقم = 7
if رقم % 2 == 0:
    print("زوجي")
else:
    print("فردي")
```

**JavaScript:**
```javascript
let رقم = 7;
if (رقم % 2 === 0) {
    console.log("زوجي");
} else {
    console.log("فردي");
}
```

الفكرة متطابقة. الصياغة مختلفة.

لاحظ: تستخدم Python المسافات البادئة (indentation) لتحديد الكتل (blocks). أما JavaScript فتستخدم الأقواس المعقوفة `{}`. كلاهما ينجح — إنها مجرد اختيارات مختلفة اتخذها مصممو اللغات.

## 2. الأسماء الكبرى وفيم تُستخدم

| اللغة | نقطة القوة | تُستخدم عادةً في |
|------|----------|-----------------------|
| Python | القابلية للقراءة، البيانات، الذكاء الاصطناعي | السكريبتات، تحليل البيانات، الواجهة الخلفية، التعليم |
| JavaScript | المتصفح، التفاعلية | المواقع، الواجهة الأمامية، وأيضًا الخلفية (Node.js) |
| Java | الاستقرار، الأنظمة الكبيرة | برمجيات الشركات، Android |
| C / C++ | السرعة، التحكم بالعتاد | أنظمة التشغيل، محركات الألعاب، الأنظمة المدمجة |
| SQL | الاستعلام عن قواعد البيانات | أي تطبيق يحتوي على قاعدة بيانات |

## 3. كيف تقرأ كودًا غير مألوف؟

ستصادف باستمرار خلال مسيرتك المهنية كودًا لم تره من قبل قط.
هذا أمر طبيعي. المهارة ليست في معرفة كل شيء — بل في القدرة على قراءة الخط العام للفكرة.

**الاستراتيجية:**
1. ابحث عن البنية: أين تبدأ الكتل (blocks)؟ وأين تنتهي؟
2. ابحث عن النية: ما الذي يحاول هذا الكود فعله؟
3. ابحث عن المدخلات والمخرجات: ماذا يدخل، وماذا يخرج؟
4. ابحث عن الأنماط المألوفة: if/else، الحلقات (loops)، الدوال (functions) — تبدو متشابهة في كل لغة تقريبًا

**مثال — لغة غير مألوفة (Ruby):**
```ruby
رقم = 7
if رقم % 2 == 0
  puts "زوجي"
else
  puts "فردي"
end
```

قد لا تعرف Ruby. لكنك تتعرّف على `if`، و`else`، و`% 2`، وفكرة المخرجات.
أنت تفهم ما يفعله هذا الكود دون أن تكون قد تعلّمت Ruby من قبل.

## 4. JavaScript في المتصفح — جرّبها بنفسك

تتمتع JavaScript بميزة خاصة: أي حاسوب يحتوي على متصفح يحتوي بالفعل على بيئة JavaScript مدمجة.

**هكذا تفتحها:**
1. افتح Chrome أو Firefox أو Edge
2. اضغط F12 (أو انقر بالزر الأيمن ← "فحص العنصر / Inspect")
3. انقر على تبويب "Console"
4. اكتب هنا كود JavaScript ثم اضغط Enter

جرّب:
```javascript
console.log("مرحبا بالعالم");
```

ثم:
```javascript
let x = 5;
let y = 3;
console.log(x + y);
```

ينفّذه المتصفح فورًا. بلا تثبيت، وبلا إعدادات.

## 5. Python — اللغة التي تُقرأ وكأنها إنجليزية

صُممت Python بهدف واضح واحد: **القابلية للقراءة**.

كتب مبتكرها، غيدو فان روسوم، في عام 1991 لغةً تحمل فيها المسافات البيضاء معنى، ولا تحتاج فيها إلى فواصل منقوطة، ويكاد الكود فيها يُقرأ كأنه نثر.

```python
أسماء = ["Ali", "Fatima", "Jonas"]

for اسم in أسماء:
    print("مرحبًا، " + اسم)
```

يفعل هذا بالضبط ما تقوله الجملة: لكل اسم في القائمة، يطبع تحية.

تحظى Python بشعبية كبيرة في التعليم، وتحليل البيانات، والذكاء الاصطناعي، والسكريبتات. إنها اللغة التي تختارها عندما تريد بناء شيء ما بسرعة، وتكون القابلية للقراءة مهمة بالنسبة لك.

## 6. ما هي اللغة التي تتعلمها أولًا؟

الإجابة الصادقة: الأمر أقل أهمية مما تعتقد.

إذا تعلّمت JavaScript، ستفهم Python بشكل أسرع لاحقًا. وإذا تعلّمت Python، ستفهم JavaScript بشكل أسرع لاحقًا. المفاهيم الأساسية — المتغيرات، الشروط، الحلقات، الدوال — موجودة في كل لغة.

اختر بناءً على:
- **ما الذي تريد بناءه** — موقع إلكتروني؟ اختر JavaScript. تحليل بيانات؟ اختر Python. تطبيق؟ اختر Swift أو Kotlin.
- **ما الذي تستخدمه بيئتك** — إذا كان زملاؤك يكتبون بلغة Python، فابدأ بـ Python.
- **ما الذي يحفّزك** — تتعلّم بشكل أسرع مع اللغة التي تُحمّسك.

في هذه الدورة، نستخدم JavaScript لتمارين المتصفح (بلا حاجة للتثبيت) وPython لمفاهيم الواجهة الخلفية (backend).
