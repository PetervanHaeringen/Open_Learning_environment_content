# Модуль 4 — Сравнение языков

Существуют сотни языков программирования. Вам не нужно знать их все.
Но вам нужно понимать, почему их так много — и как выбирать.

---

## 1. Одна и та же задача, три языка

Начнём с простого алгоритма: определить, чётное число или нечётное.

**Псевдокод** — не настоящий язык, просто запись идеи:
```
если число делится на 2:
    вывести "чётное"
иначе:
    вывести "нечётное"
```

**Python:**
```python
число = 7
if число % 2 == 0:
    print("чётное")
else:
    print("нечётное")
```

**JavaScript:**
```javascript
let число = 7;
if (число % 2 === 0) {
    console.log("чётное");
} else {
    console.log("нечётное");
}
```

Идея одинакова. Написание — разное.

Обратите внимание: Python использует отступы (пробелы) для обозначения блоков. JavaScript использует фигурные скобки `{}`. Оба варианта работают — это просто разные решения разработчиков языков.

## 2. Крупные имена и для чего они служат

| Язык | Сильная сторона | Обычно используется для |
|------|----------|-----------------------|
| Python | читаемость, данные, ИИ | скрипты, анализ данных, бэкенд, обучение |
| JavaScript | браузер, интерактивность | веб-сайты, фронтенд, также бэкенд (Node.js) |
| Java | стабильность, крупные системы | корпоративное ПО, Android |
| C / C++ | скорость, контроль над железом | операционные системы, игровые движки, встроенные системы |
| SQL | запросы к базам данных | любое приложение с базой данных |
| HTML/CSS | структура и стиль | веб-страницы (не язык программирования, но всё же код) |
| PHP | веб-серверы | WordPress, множество существующих сайтов |
| Swift / Kotlin | мобильные устройства | iOS (Swift), Android (Kotlin) |

Не существует «лучшего» языка. Каждый язык — это инструмент. Вы выбираете, исходя из задачи.

## 3. Как читать незнакомый код?

На протяжении своей карьеры вы будете постоянно сталкиваться с кодом, который никогда раньше не видели.
Это нормально. Навык заключается не в том, чтобы знать всё — а в том, чтобы уметь читать общую логику.

**Стратегия:**
1. Найдите структуру: где начинаются блоки? Где они заканчиваются?
2. Найдите намерение: что этот код пытается сделать?
3. Найдите вход и выход: что подаётся на вход, что получается на выходе?
4. Найдите знакомые паттерны: if/else, циклы, функции — они выглядят похоже практически в любом языке

**Пример — незнакомый язык (Ruby):**
```ruby
число = 7
if число % 2 == 0
  puts "чётное"
else
  puts "нечётное"
end
```

Вы можете не знать Ruby. Но вы узнаёте `if`, `else`, `% 2` и саму идею вывода.
Вы понимаете, что делает этот код, даже никогда не изучая Ruby.

## 4. JavaScript в браузере — попробуйте сами

У JavaScript есть особое преимущество: на любом компьютере с браузером уже встроена среда JavaScript.

**Вот как её открыть:**
1. Откройте Chrome, Firefox или Edge
2. Нажмите F12 (или щёлкните правой кнопкой мыши → «Просмотреть код»)
3. Перейдите на вкладку «Console» (Консоль)
4. Введите здесь JavaScript-код и нажмите Enter

Попробуйте:
```javascript
console.log("Привет, мир");
```

А затем:
```javascript
let x = 5;
let y = 3;
console.log(x + y);
```

Браузер выполняет это мгновенно. Без установки, без настройки.

## 5. Python — язык, который читается как английский

Python был создан с одной чёткой целью: **читаемость**.

Его создатель, Гвидо ван Россум, в 1991 году написал язык, в котором пробелы имеют значение, где не нужны точки с запятой и где код читается почти как проза.

```python
имена = ["Ali", "Fatima", "Jonas"]

for имя in имена:
    print("Привет, " + имя)
```

Это делает ровно то, что написано: для каждого имени в списке выводит приветствие.

Python популярен в образовании, анализе данных, ИИ и написании скриптов. Это язык, который вы выбираете, когда хотите быстро что-то построить и когда важна читаемость.

## 6. Какой язык учить первым?

Честный ответ: это имеет меньше значения, чем вы думаете.

Если вы выучите JavaScript, потом вы быстрее разберётесь в Python. Если вы выучите Python, потом вы быстрее разберётесь в JavaScript. Основные концепции — переменные, условия, циклы, функции — присутствуют в каждом языке.

Выбирайте исходя из:
- **Что вы хотите построить** — сайт? JavaScript. Анализировать данные? Python. Приложение? Swift или Kotlin.
- **Что использует ваше окружение** — если ваши коллеги пишут на Python, начните с Python.
- **Что вас мотивирует** — вы быстрее учите тот язык, который вас увлекает.

В этом курсе мы используем JavaScript для упражнений в браузере (без установки) и Python для концепций бэкенда.
