## 1. 同じ問題を、3つの言語で

まずは簡単なアルゴリズムから始めましょう：ある数が偶数か奇数かを判定する、というものです。

**擬似コード（Pseudocode）**——実在する言語ではなく、考え方をそのまま書き出したもの：
```
もし 数値 が 2 で割り切れるなら：
    「偶数」と表示する
そうでなければ：
    「奇数」と表示する
```

**Python：**
```python
数値 = 7
if 数値 % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

**JavaScript：**
```javascript
let 数値 = 7;
if (数値 % 2 === 0) {
    console.log("偶数");
} else {
    console.log("奇数");
}
```

考え方はまったく同じです。書き方（綴り方）が違うだけです。

注目してほしいのは：Pythonはインデント（空白）を使ってブロックを区切ります。JavaScriptは波括弧`{}`を使います。どちらも問題なく動作します——これは単に、言語の設計者たちが行った、それぞれ異なる選択にすぎません。

## 3. 見慣れないコードを、どう読むか？

あなたはキャリアを通じて、これまで見たことのないコードに、絶えず出会うことになります。
それは普通のことです。大切なのは、すべてを知っていることではなく、大まかな流れを読み取れることです。

**戦略：**
1. 構造を探す：ブロックはどこで始まり、どこで終わるか？
2. 意図を探す：このコードは何をしようとしているのか？
3. 入力と出力を探す：何が入り、何が出てくるのか？
4. 見慣れたパターンを探す：if/else、ループ、関数——これらは、どの言語でも似たような見た目をしています

**例——見慣れない言語（Ruby）：**
```ruby
数値 = 7
if 数値 % 2 == 0
  puts "偶数"
else
  puts "奇数"
end
```

あなたはRubyを知らないかもしれません。しかし、`if`、`else`、`% 2`、そして「出力」という考え方は認識できるはずです。
Rubyを一度も学んだことがなくても、このコードが何をしているかは理解できます。

## 5. Python——英語のように読める言語

Pythonは、たったひとつの明確な目的のために設計されました：**可読性**です。

その生みの親であるグイド・ヴァンロッサムは、1991年に、空白に意味があり、セミコロンが不要で、コードがほとんど散文のように読める言語を書き上げました。

```python
名前リスト = ["Ali", "Fatima", "Jonas"]

for 名前 in 名前リスト:
    print("こんにちは、" + 名前)
```

これは、書いてある通りのことをします：リストの中の名前ひとつひとつに対して、挨拶を出力するのです。

Pythonは、教育、データ分析、AI、スクリプト作成の分野で広く使われています。何かを素早く作りたいときや、可読性を大切にしたいときに選ばれる言語です。
