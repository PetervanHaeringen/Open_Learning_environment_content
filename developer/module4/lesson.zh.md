# 模块4 — 语言之间的比较

编程语言有成百上千种。你不需要全部都会。
但你需要理解为什么会有这么多——以及该如何选择。

---

## 1. 同一个问题，三种语言

我们从一个简单的算法开始：判断一个数字是奇数还是偶数。

**伪代码**——不是真正的语言，只是把想法写下来：
```
如果 数字 能被 2 整除：
    输出 "偶数"
否则：
    输出 "奇数"
```

**Python：**
```python
数字 = 7
if 数字 % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

**JavaScript：**
```javascript
let 数字 = 7;
if (数字 % 2 === 0) {
    console.log("偶数");
} else {
    console.log("奇数");
}
```

想法完全相同。只是"写法"不同。

注意：Python用缩进（空白）来划分代码块。JavaScript则用花括号`{}`。两种方式都可行——它们只是语言设计者做出的不同选择。

## 2. 那些大名鼎鼎的语言，以及它们各自的用途

| 语言 | 强项 | 常见用途 |
|------|----------|-----------------------|
| Python | 可读性、数据处理、AI | 脚本、数据分析、后端、教学 |
| JavaScript | 浏览器、交互性 | 网站、前端，也可用于后端（Node.js） |
| Java | 稳定性、大型系统 | 企业软件、Android |
| C / C++ | 速度、对硬件的控制 | 操作系统、游戏引擎、嵌入式系统 |
| SQL | 查询数据库 | 任何带有数据库的应用 |
| HTML/CSS | 结构与样式 | 网页（严格来说不是编程语言，但也是代码） |
| PHP | Web服务器 | WordPress，以及许多现存网站 |
| Swift / Kotlin | 移动端 | iOS（Swift）、Android（Kotlin） |

没有所谓"最好"的语言。每种语言都是一种工具。你要根据要解决的问题来选择。

## 3. 如何阅读不熟悉的代码？

在你的职业生涯中，你会不断遇到之前从未见过的代码。
这很正常。真正的技能，不是什么都懂，而是能够读懂主线逻辑。

**策略：**
1. 找出结构：代码块从哪里开始？在哪里结束？
2. 找出意图：这段代码想要做什么？
3. 找出输入和输出：什么进去了？什么出来了？
4. 找出熟悉的模式：if/else、循环、函数——这些在任何语言中看起来都很相似

**举例——一种不熟悉的语言（Ruby）：**
```ruby
数字 = 7
if 数字 % 2 == 0
  puts "偶数"
else
  puts "奇数"
end
```

你可能不认识Ruby。但你能认出`if`、`else`、`% 2`，以及"输出"这个概念。
即使从没学过Ruby，你也能明白这段代码在做什么。

## 4. 浏览器里的JavaScript——自己动手试试

JavaScript有一个特别的优势：任何一台带浏览器的电脑，都已经内置了JavaScript运行环境。

**打开方式如下：**
1. 打开Chrome、Firefox或Edge浏览器
2. 按下F12（或右键点击 → "检查"）
3. 点击"Console"（控制台）标签
4. 在这里输入JavaScript代码，然后按回车

试一试：
```javascript
console.log("你好，世界");
```

然后再试：
```javascript
let x = 5;
let y = 3;
console.log(x + y);
```

浏览器会立刻执行它。不需要安装，也不需要配置。

## 5. Python——一门读起来像英语的语言

Python的设计目标非常明确：**可读性**。

它的创造者吉多·范罗苏姆（Guido van Rossum）在1991年写出了这样一门语言：空白具有意义，不需要分号，代码读起来几乎像散文一样。

```python
姓名列表 = ["Ali", "Fatima", "Jonas"]

for 姓名 in 姓名列表:
    print("你好，" + 姓名)
```

它做的事情，正如字面意思：对列表中的每一个名字，打印一句问候语。

Python在教学、数据分析、AI和脚本编写领域非常流行。当你想快速搭建点什么、并且看重可读性时，它就是你会选择的语言。

## 6. 应该先学哪一门语言？

坦诚的答案是：这远没有你想象的那么重要。

如果你先学了JavaScript，之后你会更快理解Python。如果你先学了Python，之后你也会更快理解JavaScript。那些核心概念——变量、条件判断、循环、函数——在每一门语言中都存在。

选择时可以考虑：
- **你想搭建什么**——一个网站？选JavaScript。分析数据？选Python。一个应用？选Swift或Kotlin。
- **你所在的环境用什么**——如果你的同事都写Python，那就从Python开始。
- **什么能激励你**——让你感到兴奋的语言，你会学得更快。

在这门课程中，我们用JavaScript来做浏览器练习（不需要安装），用Python来讲解后端相关的概念。
