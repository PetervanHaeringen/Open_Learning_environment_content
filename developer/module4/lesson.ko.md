# 모듈 4 — 언어 비교하기

프로그래밍 언어는 수백 가지가 존재합니다. 그것들을 모두 알 필요는 없습니다.
하지만 왜 이렇게 많은 언어가 존재하는지 — 그리고 어떻게 선택해야 하는지는 이해할 필요가 있습니다.

---

## 1. 같은 문제, 세 가지 언어

간단한 알고리즘부터 시작해 봅시다: 어떤 숫자가 짝수인지 홀수인지 판별하는 것입니다.

**의사코드(Pseudocode)** — 실제 언어가 아니라, 그냥 생각을 적어놓은 것:
```
만약 숫자가 2로 나누어떨어지면:
    "짝수"를 출력한다
그렇지 않으면:
    "홀수"를 출력한다
```

**Python:**
```python
숫자 = 7
if 숫자 % 2 == 0:
    print("짝수")
else:
    print("홀수")
```

**JavaScript:**
```javascript
let 숫자 = 7;
if (숫자 % 2 === 0) {
    console.log("짝수");
} else {
    console.log("홀수");
}
```

생각은 완전히 동일합니다. 표기 방식만 다를 뿐입니다.

주목할 점: Python은 들여쓰기(공백)를 사용해서 블록을 구분합니다. JavaScript는 중괄호 `{}`를 사용합니다. 둘 다 잘 작동합니다 — 그저 언어 설계자들이 내린 서로 다른 선택일 뿐입니다.

## 2. 유명한 언어들과 그 쓰임새

| 언어 | 강점 | 일반적인 용도 |
|------|----------|-----------------------|
| Python | 가독성, 데이터, AI | 스크립트, 데이터 분석, 백엔드, 교육 |
| JavaScript | 브라우저, 상호작용성 | 웹사이트, 프론트엔드, 백엔드에도 사용됨(Node.js) |

| SQL | 데이터베이스 조회 | 데이터베이스를 사용하는 모든 애플리케이션 |
| HTML/CSS | 구조와 스타일 | 웹 페이지 (프로그래밍 언어는 아니지만 코드는 맞음) |

"최고의" 언어라는 것은 존재하지 않습니다. 모든 언어는 하나의 도구입니다. 당신은 문제에 따라 선택합니다.

## 3. 낯선 코드는 어떻게 읽을까?

당신은 경력을 쌓아가는 내내, 한 번도 본 적 없는 코드를 끊임없이 마주하게 될 것입니다.
그것은 자연스러운 일입니다. 중요한 기술은 모든 것을 아는 것이 아니라, 전체적인 흐름을 읽어낼 수 있는 능력입니다.

**전략:**
1. 구조를 찾아라: 블록은 어디서 시작하고, 어디서 끝나는가?
2. 의도를 찾아라: 이 코드는 무엇을 하려고 하는가?
3. 입력과 출력을 찾아라: 무엇이 들어가고, 무엇이 나오는가?
4. 익숙한 패턴을 찾아라: if/else, 반복문, 함수 — 이것들은 어떤 언어에서도 비슷하게 생겼습니다

**예시 — 낯선 언어 (Ruby):**
```ruby
숫자 = 7
if 숫자 % 2 == 0
  puts "짝수"
else
  puts "홀수"
end
```

당신은 Ruby를 모를 수도 있습니다. 하지만 `if`, `else`, `% 2`, 그리고 출력이라는 개념은 알아볼 수 있습니다.
Ruby를 배운 적이 없어도, 이 코드가 무엇을 하는지 이해할 수 있습니다.

## 4. 브라우저 속 JavaScript — 직접 해보세요

JavaScript에는 특별한 장점이 있습니다: 브라우저가 설치된 모든 컴퓨터에는 이미 JavaScript 실행 환경이 내장되어 있다는 점입니다.

**여는 방법은 다음과 같습니다:**
1. Chrome, Firefox, 또는 Edge를 엽니다
2. F12를 누릅니다 (또는 오른쪽 클릭 → "검사")
3. "Console" 탭을 클릭합니다
4. 여기에 JavaScript를 입력하고 Enter를 누릅니다

시도해 보세요:
```javascript
console.log("안녕하세요, 세계");
```

그다음:
```javascript
let x = 5;
let y = 3;
console.log(x + y);
```

브라우저가 즉시 실행합니다. 설치도, 설정도 필요 없습니다.

## 5. Python — 영어처럼 읽히는 언어

Python은 단 하나의 명확한 목표를 가지고 설계되었습니다: **가독성**입니다.

만든 사람인 귀도 반 로섬은 1991년, 공백이 의미를 가지고, 세미콜론이 필요 없으며, 코드가 거의 산문처럼 읽히는 언어를 만들었습니다.

```python
이름목록 = ["Ali", "Fatima", "Jonas"]

for 이름 in 이름목록:
    print("안녕하세요, " + 이름)
```

이 코드는 정확히 적힌 그대로의 일을 합니다: 목록에 있는 각 이름마다 인사말을 출력합니다.

Python은 교육, 데이터 분석, AI, 스크립트 작성 분야에서 인기가 많습니다. 무언가를 빠르게 만들고 싶고, 가독성이 중요할 때 선택하는 언어입니다.

## 6. 어떤 언어를 먼저 배워야 할까요?

솔직한 답은: 당신이 생각하는 것보다 덜 중요하다는 것입니다.

JavaScript를 배우면, 이후 Python을 더 빨리 이해하게 됩니다. Python을 배우면, 이후 JavaScript를 더 빨리 이해하게 됩니다. 변수, 조건문, 반복문, 함수 같은 핵심 개념은 모든 언어에 존재합니다.

다음을 기준으로 선택하세요:
- **무엇을 만들고 싶은가** — 웹사이트? JavaScript. 데이터 분석? Python. 앱? Swift 또는 Kotlin.
- **당신의 환경이 무엇을 사용하는가** — 동료들이 Python을 쓴다면, Python으로 시작하세요.
- **무엇이 당신에게 동기를 주는가** — 흥미를 느끼는 언어일수록 더 빨리 배우게 됩니다.

이 과정에서는 브라우저 실습에는 JavaScript(설치 불필요)를, 백엔드 개념에는 Python을 사용합니다.
