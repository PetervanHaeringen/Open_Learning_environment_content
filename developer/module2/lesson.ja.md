機械が指示に従うことができる、という考え方は、決して当たり前のものではありません。
誰かが、それを思いつかなければなりませんでした。そしてその前に、誰かがそう考える勇気を持たなければなりませんでした。

## 1. チャールズ・バベッジ——決して完成しなかった機械（1820年代）

チャールズ・バベッジは、あるひとつの執念にとりつかれたイギリスの数学者でした。それは、計算表の中に潜む誤りです。

彼の時代、航海、砲術、税務のための数学的な表は、人の手によって計算されていました。そして人間は間違えます。バベッジは、間違えない機械が欲しかったのです。

彼は**階差機関（Difference Engine）**を設計しました。歯車とレバーでできた機械式計算機です。そして後には**解析機関（Analytical Engine）**も設計しました。これは計算だけでなく、パンチカードによってプログラムすることもできる機械でした。

解析機関は、現代のコンピューターが持つすべての要素を備えていました：
- 「ミル（mill）」（処理装置）
- 「ストア（store）」（記憶装置）
- パンチカードによる入力
- プリンターによる出力

バベッジは、それを完成させることはできませんでした。当時の技術は、それほど精密ではなかったのです。しかし、そのアイデアは、たしかにそこに存在していました。

## 2. エイダ・ラブレス——最初のプログラマー（1843年）

エイダ・ラブレスは、詩人バイロン卿の娘であり、母親は数学的な素養を持つ人でした。
彼女は17歳のときにバベッジと出会い、彼の機械に魅了されました。

1843年、彼女は解析機関に関する論文をフランス語から英語へと翻訳しました。しかし、彼女が加えたものは、単なる翻訳をはるかに超えていました——彼女は詳細な注釈を書き加え、その結果、原文の3倍の長さになったのです。

その注釈の中で、彼女は次のことを記しました：
- その機械が、単なる計算以上のことに使える可能性
- 同じ指示を機械に繰り返し実行させる方法（史上初の「ループ」）
- ベルヌーイ数を計算するための、段階的な手順——機械のために書かれた、史上初のアルゴリズム

しかし、彼女を本当に際立たせていたのは、その洞察力でした：この機械が扱っているのは*記号*であって、単なる数字だけではない、ということです。彼女は、音楽を記号に置き換えさえすれば、解析機関は作曲すらできるだろう、とまで書き記しています。

その洞察こそが、あらゆる現代のコンピューターの基礎となっています。

> 「この機械にできるのは、私たちが命じたことだけです。」
> ——エイダ・ラブレス

彼女は36歳でこの世を去りました。彼女の業績が再発見されたのは、それから1世紀も後のことでした。

## 3. アラン・チューリング——機械は思考できるのか？（1936年）

アラン・チューリングは、世界を変える問いを投げかけたイギリスの数学者でした。

**機械が計算できることには、どのような限界があるのか？**

1936年——まだコンピューターというものが存在しなかった時代に——彼は、ある架空の機械について記述しました。それが**チューリングマシン**です。記号が書かれた無限に長いテープ、記号を読み書きする読み取りヘッド、そして次に何が起こるかを決めるルールの集合体です。

この抽象的なモデルは、そもそも実行可能なあらゆる計算を行うことができました。
これによってチューリングは、どれほど強力な機械であっても、*決して*解くことのできない計算が存在することを証明したのです。

第二次世界大戦中、チューリングは彼のチームとともに、ナチスの暗号「エニグマ」を解読しました——これにより、戦争はおよそ2年短縮されたと推定されています。

戦後、彼は今なおプログラマーたちを悩ませ続けている、ある問いを投げかけました。

**機械は思考できるのか？**

彼は**チューリングテスト**を考案しました。もし人間が、文章によるやりとりだけでは、相手が人間なのか機械なのかを見分けられなかったとしたら、その機械は知性のテストに「合格した」とみなされる、というものです。

チューリングは、自らの同性愛を理由にイギリス政府から訴追を受け、1954年に亡くなりました。おそらく自殺であったとされています。2013年、イギリス国王によって、死後に恩赦が与えられました。

## 4. バベッジから現在へと続く系譜

```
バベッジ（1820年代）        → アイデアの誕生：指示に従う機械
ラブレス（1843年）          → 最初のアルゴリズム、最初のループ
チューリング（1936年）      → 理論：機械は何を計算できるのか？
ENIAC（1945年）             → 最初の本格的な電子計算機
トランジスタ（1947年）      → より小さく、より速く、より安く
集積回路                    → さらに小さく
パーソナルコンピューター    → すべての家庭のリビングへ
インターネット              → すべてがつながる
スマートフォン              → すべての人のポケットへ
AI（現在）                  → パターンを自ら学習する機械
```

それぞれの段階は、前の段階の上に積み重なってきました。そして、それぞれの段階は、誰かが問いを投げかけることから始まりました。

---

## 5. これは、あなたにとって何を意味するのか？

あなたは今、この系譜の終着点に立っています——そして同時に、何か新しいものの出発点にも立っているのです。

あなたがこれから使うツールは、魅力的な問いを投げかけ続けてきた人々の、80年にわたる努力の結晶です。ラブレスは問いました：計算以外に、機械には何ができるのか？チューリングは問いました：その限界はどこにあるのか？Pythonの創造者たちは問いました：人間が読めるコードを、どう書けばよいのか？

開発者として、あなたもまた、自分自身の問いを投げかけていくことになります。そして、あなたが書く答えもまた、同じ系譜の一部になっていくのです。
