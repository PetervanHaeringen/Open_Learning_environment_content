## 1. 查尔斯·巴贝奇——那台永远没有完工的机器（19世纪20年代）

查尔斯·巴贝奇是一位英国数学家，他有一个执念：计算表里的错误。

在他所处的年代，用于航海、炮兵、税务的数学表格，都是靠人手工计算出来的。而人是会犯错的。巴贝奇想要一台不会犯错的机器。

他设计了**差分机（Difference Engine）**：一台由齿轮和杠杆组成的机械计算器。后来，他又设计了**分析机（Analytical Engine）**：这台机器不仅能计算，还能用打孔卡进行编程。

分析机拥有现代计算机所具备的一切：
- "mill"（磨坊，也就是处理器）
- "store"（存储，也就是内存）
- 通过打孔卡输入
- 通过打印机输出

巴贝奇终其一生都没能把它建成。他所处时代的技术，还不够精密。但这个想法，已经存在了。

## 2. 阿达·洛芙莱斯——第一位程序员（1843年）

阿达·洛芙莱斯是诗人拜伦勋爵的女儿，母亲也精通数学。
她17岁时结识了巴贝奇，从此被他的机器深深吸引。

1843年，她把一篇关于分析机的法语文章翻译成了英语。但她添加的内容远不止是一份翻译——她写下了大量注释，篇幅是原文的三倍。

在那些注释中，她描述了：
- 这台机器除了计算之外，还能被用来做什么
- 如何让机器反复执行相同的指令（这是历史上第一个"循环"）
- 一份计算伯努利数的分步方案——这是史上第一个专为机器编写的算法

但真正让她与众不同的，是她的洞察力：这台机器处理的是*符号*，而不仅仅是数字。她写道，只要把音乐转化成符号，分析机甚至可以用来作曲。

正是这个洞察，构成了所有现代计算机的基础。

> "这台机器只能做我们命令它去做的事。"
> ——阿达·洛芙莱斯

她在36岁那年去世。她的成果直到一个世纪之后才被重新发现。

## 3. 阿兰·图灵——机器能思考吗？（1936年）

阿兰·图灵是一位英国数学家，他提出了一个改变了世界的问题：

**一台机器能计算的极限在哪里？**

1936年——在任何计算机诞生之前——他描述了一台假想中的机器：**图灵机**。一条无限长的、带有符号的纸带，一个能够读写符号的读写头，以及一套规则，用来决定接下来会发生什么。

这个抽象模型能够执行任何原则上可以被执行的计算。
图灵借此证明：存在着一些计算，无论机器多么强大，*永远*无法被解决。

第二次世界大战期间，图灵和他的团队破解了纳粹的恩尼格玛密码——据估计，这使战争缩短了两年。

战后，他提出了一个至今仍萦绕在程序员心头的问题：

**机器能思考吗？**

他设计了**图灵测试**：如果一个人通过文字交流，无法分辨自己是在跟人类交谈，还是在跟机器交谈，那么这台机器就在"智能"这一关上"通过了"。

图灵因其同性恋身份而遭到英国政府的起诉，于1954年去世，据信是自杀。2013年，英国君主追授他赦免。

## 4. 从巴贝奇到今天的这条脉络

```
巴贝奇（19世纪20年代）      → 想法的诞生：一台能遵循指令的机器
洛芙莱斯（1843年）          → 第一个算法，第一个循环
图灵（1936年）              → 理论：机器能计算什么？
ENIAC（1945年）             → 第一台真正的电子计算机
晶体管（1947年）            → 更小、更快、更便宜
集成电路                    → 更加微小
个人电脑                    → 走进千家万户
互联网                      → 彼此互联
智能手机                    → 装进每个人的口袋
AI（现在）                  → 机器自己学习规律和模式
```

每一步，都建立在前一步的基础之上。而每一步，都始于有人提出了一个问题。

---

## 5. 这对你意味着什么？

你正站在这条脉络的末端——同时，也站在某种新事物的起点。

你即将使用的这些工具，是那些提出了迷人问题的人们，历经八十年工作而积累下来的成果。洛芙莱斯问：机器除了计算之外，还能做什么？图灵问：极限在哪里？Python的创造者们问：我们怎样才能写出人类也能读懂的代码？

作为一名开发者，你也会提出属于你自己的问题。而你写下的答案，也将成为这条脉络的一部分。
