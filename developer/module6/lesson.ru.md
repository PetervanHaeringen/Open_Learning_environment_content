# Модуль 6 — Строительные блоки программы

Вы прочувствовали алгоритмы своими руками. Теперь вы будете их записывать.
Откройте консоль браузера (F12 → Console) и печатайте вместе с чтением.

---

## 1. Переменные — дать имя значениям

Переменная — это имя, которое хранит значение.

```javascript
let имя = "Ali";
let возраст = 23;
let активен = true;
```

- `let` создаёт новую переменную
- `имя`, `возраст`, `активен` — это имена
- Значения справа от `=` сохраняются

Введите это в консоли и нажимайте Enter после каждой строки.
Затем введите `имя` и нажмите Enter — консоль покажет «Ali».

**Три типа значений:**
- Текст (string): `"Ali"` — всегда в кавычках
- Число (number): `23` — без кавычек
- Истина/ложь (boolean): `true` или `false`

---

## 2. Условия — принятие решений

```javascript
let температура = 22;

if (температура > 25) {
    console.log("Тепло — возьмите воду");
} else {
    console.log("Прохладно — куртка не помешает");
}
```

Введите это в консоли. Затем измените `22` на `30` и запустите снова.

Структура всегда такая:
```javascript
if (условие) {
    // делай это, если условие истинно
} else {
    // делай это, если условие неистинно
}
```

**Операторы сравнения:**
| Оператор | Значение |
|----------|-----------|
| `>` | больше чем |
| `<` | меньше чем |
| `>=` | больше или равно |
| `<=` | меньше или равно |
| `===` | точно равно |
| `!==` | не равно |

## 3. Циклы — повторение

**Цикл for** — когда вы знаете, сколько раз хотите повторить что-то:

```javascript
for (let i = 1; i <= 5; i++) {
    console.log("Шаг " + i);
}
```

Это выводит «Шаг 1» и до «Шаг 5».

Три части в скобках:
1. `let i = 1` — начать с 1
2. `i <= 5` — продолжать, пока i меньше или равно 5
3. `i++` — увеличивать i на 1 после каждого шага

**Цикл while** — когда вы не знаете, сколько раз:

```javascript
let счётчик = 1;

while (счётчик <= 5) {
    console.log("Счётчик сейчас: " + счётчик);
    счётчик++;
}
```

Тот же результат, другой способ записи. Используйте `while`, когда условие остановки зависит от чего-то, что меняется во время работы программы.

## 4. Функции — переиспользуемые блоки

Функция — это блок кода с именем. Вы пишете его один раз и используете много раз.

```javascript
function поприветствовать(имя) {
    console.log("Привет, " + имя + "!");
}

поприветствовать("Ali");
поприветствовать("Fatima");
поприветствовать("Jonas");
```

Функция `поприветствовать` ожидает **параметр** — `имя`.
Каждый раз, вызывая функцию, вы передаёте другое значение.

**Функции, возвращающие значение:**

```javascript
function квадрат(число) {
    return число * число;
}

let результат = квадрат(4);
console.log(результат);
```

`return` отправляет значение обратно. Вы можете сохранить его или использовать напрямую.

## 5. Всё вместе — мини-программа

```javascript
function оценить(балл) {
    if (балл >= 90) {
        return "Отлично";
    } else if (балл >= 70) {
        return "Хорошо";
    } else if (балл >= 55) {
        return "Удовлетворительно";
    } else {
        return "Неудовлетворительно";
    }
}

let баллы = [88, 42, 95, 67, 55];

for (let i = 0; i < баллы.length; i++) {
    let оценка = оценить(баллы[i]);
    console.log("Балл " + баллы[i] + ": " + оценка);
}
```

Перепишите это в консоли. Посмотрите, что происходит.
Затем измените один балл и запустите снова.

Это настоящая программа: у неё есть вход, обработка и выход.
