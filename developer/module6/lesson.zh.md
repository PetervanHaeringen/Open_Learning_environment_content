# 模块6 — 程序的构建模块

你已经用双手体验过算法了。现在，你要把它们写出来。
打开浏览器控制台（F12 → Console），一边阅读一边跟着输入。

---

## 1. 变量——给数值起个名字

变量就是一个用来存放数值的名字。

```javascript
let 姓名 = "Ali";
let 年龄 = 23;
let 激活 = true;
```

- `let` 用来创建一个新变量
- `姓名`、`年龄`、`激活` 就是这些变量的名字
- `=` 右边的值会被存储起来

在控制台中输入这些内容，每写完一行就按回车。
然后再输入 `姓名`，按回车——控制台会显示"Ali"。

**三种基本的值类型：**
- 文本（string）：`"Ali"`——总是被引号包住
- 数字（number）：`23`——不需要引号
- 真/假（boolean）：`true` 或 `false`

---

## 2. 条件——做出判断

```javascript
let 温度 = 22;

if (温度 > 25) {
    console.log("很热——记得带水");
} else {
    console.log("凉爽——带件外套比较合适");
}
```

在控制台里输入这段代码。然后把`22`改成`30`，再运行一次。

它的结构永远是这样：
```javascript
if (条件) {
    // 如果条件为真，就执行这里
} else {
    // 如果条件不为真，就执行这里
}
```

**比较运算符：**
| 运算符 | 含义 |
|----------|-----------|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `===` | 完全相等 |
| `!==` | 不相等 |

## 3. 循环——重复执行

**for循环**——当你知道要重复几次时使用：

```javascript
for (let i = 1; i <= 5; i++) {
    console.log("第" + i + "步");
}
```

这会依次打印"第1步"到"第5步"。

括号中间的三个部分：
1. `let i = 1`——从1开始
2. `i <= 5`——只要i小于等于5，就继续
3. `i++`——每一步之后，把i加1

**while循环**——当你不知道要重复几次时使用：

```javascript
let 计数器 = 1;

while (计数器 <= 5) {
    console.log("计数器现在是: " + 计数器);
    计数器++;
}
```

结果完全相同，只是写法不同。当停止的条件依赖于程序运行过程中会变化的东西时，就使用`while`。

---

## 4. 函数——可以重复使用的代码块

函数是一段带有名字的代码块。你只写一次，却可以多次使用它。

```javascript
function 问候(姓名) {
    console.log("你好，" + 姓名 + "！");
}

问候("Ali");
问候("Fatima");
问候("Jonas");
```

函数`问候`需要一个**参数（parameter）**——`姓名`。
每次调用这个函数时，你可以传入一个不同的值。

**能够返回一个值的函数：**

```javascript
function 平方(数字) {
    return 数字 * 数字;
}

let 结果 = 平方(4);
console.log(结果);
```

`return` 把一个值送回去。你可以把它保存下来，也可以直接使用。

## 5. 把一切结合起来——一个迷你程序

```javascript
function 评级(分数) {
    if (分数 >= 90) {
        return "优秀";
    } else if (分数 >= 70) {
        return "良好";
    } else if (分数 >= 55) {
        return "及格";
    } else {
        return "不及格";
    }
}

let 分数列表 = [88, 42, 95, 67, 55];

for (let i = 0; i < 分数列表.length; i++) {
    let 评价 = 评级(分数列表[i]);
    console.log("分数 " + 分数列表[i] + ": " + 评价);
}
```

把这段代码抄到控制台里。看看会发生什么。
然后改动其中一个分数，再运行一次。

这是一个真正的程序：它有输入、处理、和输出。
