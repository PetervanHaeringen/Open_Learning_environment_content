# 모듈 6 — 프로그램의 구성 요소

당신은 손으로 알고리즘을 직접 느껴보았습니다. 이제는 그것을 글로 써볼 차례입니다.
브라우저 콘솔을 열고(F12 → Console), 읽으면서 함께 입력해 보세요.

---

## 1. 변수 — 값에 이름 붙이기

변수란 값을 담고 있는 이름입니다.

```javascript
let 이름 = "Ali";
let 나이 = 23;
let 활성 = true;
```

- `let`은 새로운 변수를 만듭니다
- `이름`, `나이`, `활성`이 그 이름들입니다
- `=`의 오른쪽에 있는 값들이 저장됩니다

이것을 콘솔에 입력하고, 각 줄마다 Enter를 누르세요.
그다음 `이름`을 입력하고 Enter를 누르면 — 콘솔에 "Ali"가 표시됩니다.

**세 가지 종류의 값:**
- 텍스트(string): `"Ali"` — 항상 따옴표 안에
- 숫자(number): `23` — 따옴표 없이
- 참/거짓(boolean): `true` 또는 `false`

---

## 2. 조건문 — 결정 내리기

```javascript
let 온도 = 22;

if (온도 > 25) {
    console.log("따뜻함 — 물을 챙기세요");
} else {
    console.log("선선함 — 겉옷이 유용할 거예요");
}
```

이것을 콘솔에 입력해 보세요. 그런 다음 `22`를 `30`으로 바꾸고 다시 실행해 보세요.

구조는 항상 이렇습니다:
```javascript
if (조건) {
    // 조건이 참이면 이것을 실행
} else {
    // 조건이 참이 아니면 이것을 실행
}
```

**비교 연산자:**
| 연산자 | 의미 |
|----------|-----------|
| `>` | 크다 |
| `<` | 작다 |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |
| `===` | 정확히 같다 |
| `!==` | 같지 않다 |

## 3. 반복문 — 반복하기

**for 반복문** — 무언가를 몇 번 반복할지 알고 있을 때:

```javascript
for (let i = 1; i <= 5; i++) {
    console.log("단계 " + i);
}
```

이것은 "단계 1"부터 "단계 5"까지 출력합니다.

괄호 안의 세 부분:
1. `let i = 1` — 1부터 시작
2. `i <= 5` — i가 5 이하인 동안 계속
3. `i++` — 각 단계 후에 i를 1씩 증가

**while 반복문** — 몇 번인지 모를 때:

```javascript
let 카운터 = 1;

while (카운터 <= 5) {
    console.log("카운터는 현재: " + 카운터);
    카운터++;
}
```

결과는 같지만, 표현 방식이 다릅니다. 멈추는 조건이 프로그램 실행 중에 변하는 무언가에 달려 있을 때는 `while`을 사용하세요.

## 4. 함수 — 재사용 가능한 블록

함수란 이름이 붙은 코드 블록입니다. 한 번 작성하면 여러 번 사용할 수 있습니다.

```javascript
function 인사하기(이름) {
    console.log("안녕하세요, " + 이름 + "님!");
}

인사하기("Ali");
인사하기("Fatima");
인사하기("Jonas");
```

함수 `인사하기`는 **매개변수(parameter)** — `이름` — 을 필요로 합니다.
함수를 호출할 때마다, 다른 값을 전달할 수 있습니다.

**값을 반환하는 함수:**

```javascript
function 제곱(숫자) {
    return 숫자 * 숫자;
}

let 결과 = 제곱(4);
console.log(결과);
```

`return`은 값을 다시 돌려보냅니다. 그 값을 저장하거나 바로 사용할 수 있습니다.

## 5. 모두 합치기 — 미니 프로그램

```javascript
function 등급매기기(점수) {
    if (점수 >= 90) {
        return "우수";
    } else if (점수 >= 70) {
        return "양호";
    } else if (점수 >= 55) {
        return "보통";
    } else {
        return "미달";
    }
}

let 점수목록 = [88, 42, 95, 67, 55];

for (let i = 0; i < 점수목록.length; i++) {
    let 등급 = 등급매기기(점수목록[i]);
    console.log("점수 " + 점수목록[i] + ": " + 등급);
}
```

이것을 콘솔에 옮겨 입력해 보세요. 무슨 일이 일어나는지 확인해 보세요.
그런 다음 점수 하나를 바꾸고 다시 실행해 보세요.

이것은 진짜 프로그램입니다: 입력, 처리, 출력을 모두 갖추고 있습니다.
