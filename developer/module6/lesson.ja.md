# モジュール6 — プログラムを組み立てる部品たち

あなたはこれまで、アルゴリズムを手で感じてきました。今度は、それを書き記していきます。
ブラウザのコンソールを開き（F12 → Console）、読みながら一緒に入力してみましょう。

---

## 1. 変数——値に名前をつける

変数とは、値を保持しておくための名前のことです。

```javascript
let 名前 = "Ali";
let 年齢 = 23;
let 有効 = true;
```

- `let` は新しい変数を作成します
- `名前`、`年齢`、`有効` が変数の名前です
- `=` の右側にある値が保存されます

これをコンソールに入力し、1行ごとにEnterキーを押してください。
次に `名前` と入力してEnterを押すと——コンソールには「Ali」と表示されます。

**3種類の値：**
- テキスト（string）：`"Ali"`——常に引用符で囲む
- 数値（number）：`23`——引用符は不要
- 真/偽（boolean）：`true` または `false`

---

## 2. 条件——判断を下す

```javascript
let 気温 = 22;

if (気温 > 25) {
    console.log("暑い——水を持っていこう");
} else {
    console.log("涼しい——上着があると便利");
}
```

これをコンソールに入力してください。次に`22`を`30`に変えて、もう一度実行してみましょう。

構造は、いつもこうなっています：
```javascript
if (条件) {
    // 条件が真なら、これを行う
} else {
    // 条件が真でなければ、これを行う
}
```

**比較演算子：**
| 演算子 | 意味 |
|----------|-----------|
| `>` | より大きい |
| `<` | より小さい |
| `>=` | 以上 |
| `<=` | 以下 |
| `===` | 完全に等しい |
| `!==` | 等しくない |

## 3. ループ——繰り返し

**forループ**——何回繰り返したいかがわかっているとき：

```javascript
for (let i = 1; i <= 5; i++) {
    console.log("ステップ " + i);
}
```

これは「ステップ 1」から「ステップ 5」まで出力します。

括弧の中にある3つの部分：
1. `let i = 1`——1から始める
2. `i <= 5`——iが5以下である限り続ける
3. `i++`——各ステップの後にiを1増やす

**whileループ**——何回繰り返すかがわからないとき：

```javascript
let カウンター = 1;

while (カウンター <= 5) {
    console.log("カウンターは今: " + カウンター);
    カウンター++;
}
```

結果は同じですが、書き方が違います。停止条件が、プログラムの実行中に変化する何かに依存している場合には、`while`を使います。

---

## 4. 関数——再利用できるブロック

関数とは、名前のついたコードのブロックのことです。一度書けば、何度も使い回すことができます。

```javascript
function 挨拶(名前) {
    console.log("こんにちは、" + 名前 + "さん！");
}

挨拶("Ali");
挨拶("Fatima");
挨拶("Jonas");
```

関数`挨拶`は**引数（parameter）**——`名前`——を必要とします。
関数を呼び出すたびに、異なる値を渡すことができます。

**値を返す関数：**

```javascript
function 二乗(数値) {
    return 数値 * 数値;
}

let 結果 = 二乗(4);
console.log(結果);
```

`return`は値を呼び出し元へ送り返します。それを保存することも、そのまま使うこともできます。

## 5. すべてを組み合わせる——ミニプログラム

```javascript
function 評価する(点数) {
    if (点数 >= 90) {
        return "優秀";
    } else if (点数 >= 70) {
        return "良好";
    } else if (点数 >= 55) {
        return "合格";
    } else {
        return "不合格";
    }
}

let 点数一覧 = [88, 42, 95, 67, 55];

for (let i = 0; i < 点数一覧.length; i++) {
    let 評価 = 評価する(点数一覧[i]);
    console.log("点数 " + 点数一覧[i] + ": " + 評価);
}
```

これをコンソールに書き写してみてください。何が起こるか見てみましょう。
それから、点数をひとつ変えて、もう一度実行してみましょう。

これは本物のプログラムです：入力、処理、そして出力があります。

## 6. 練習問題

ブラウザのコンソールで、次の課題に挑戦してみましょう：

**課題1：** ある数が偶数なら`true`を、奇数なら`false`を返す関数`偶数か`を書いてください。数値4、7、12、9でテストしてみましょう。

**課題2：** 3の段の掛け算表（3、6、9、……30まで）を出力するループを書いてください。

**課題3：** 5つの名前が入ったリストを作ってください。そのリストをループで回し、それぞれの名前を「ようこそ、[名前]さん！」という形式で出力してください。

*ヒント：リスト（配列）には `let 名前一覧 = ["名前1", "名前2", ...]` を使います。*
