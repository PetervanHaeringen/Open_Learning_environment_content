# الوحدة 6 — اللبنات الأساسية للبرنامج

لقد شعرتَ بالخوارزميات بيديك. الآن ستكتبها.
افتح طرفية المتصفح (F12 ← Console) واكتب معنا بينما تقرأ.

---

## 1. المتغيرات — إعطاء اسم للقيم

المتغيّر هو اسم يحمل قيمة ما.

```javascript
let الاسم = "Ali";
let العمر = 23;
let نشط = true;
```

- `let` تُنشئ متغيّرًا جديدًا
- `الاسم`، `العمر`، `نشط` هي الأسماء
- تُحفظ القيم الموجودة على يمين علامة `=`

اكتب هذا في الطرفية واضغط Enter بعد كل سطر.
ثم اكتب `الاسم` واضغط Enter — ستُظهر الطرفية "Ali".

**ثلاثة أنواع من القيم:**
- النص (string): `"Ali"` — دائمًا بين علامتَي اقتباس
- الرقم (number): `23` — بدون علامات اقتباس
- صح/خطأ (boolean): `true` أو `false`

---

## 2. الشروط — اتخاذ القرارات

```javascript
let درجة_الحرارة = 22;

if (درجة_الحرارة > 25) {
    console.log("دافئ — احمل معك ماءً");
} else {
    console.log("بارد — سترة قد تفيدك");
}
```

اكتب هذا في الطرفية. ثم غيّر `22` إلى `30` ونفّذه مجددًا.

البنية دائمًا هي:
```javascript
if (الشرط) {
    // افعل هذا إذا كان الشرط صحيحًا
} else {
    // افعل هذا إذا لم يكن الشرط صحيحًا
}
```

**عوامل المقارنة:**
| العامل | المعنى |
|----------|-----------|
| `>` | أكبر من |
| `<` | أصغر من |
| `>=` | أكبر من أو يساوي |
| `<=` | أصغر من أو يساوي |
| `===` | يساوي تمامًا |
| `!==` | لا يساوي |

## 3. الحلقات (Loops) — التكرار

**حلقة for** — عندما تعرف كم مرة تريد تكرار شيء ما:

```javascript
for (let i = 1; i <= 5; i++) {
    console.log("الخطوة " + i);
}
```

هذا يطبع "الخطوة 1" حتى "الخطوة 5".

الأجزاء الثلاثة بين الأقواس:
1. `let i = 1` — ابدأ من 1
2. `i <= 5` — استمر طالما i أصغر من أو يساوي 5
3. `i++` — زد i بمقدار 1 بعد كل خطوة

**حلقة while** — عندما لا تعرف كم مرة:

```javascript
let العداد = 1;

while (العداد <= 5) {
    console.log("العداد الآن هو: " + العداد);
    العداد++;
}
```

نفس النتيجة، بطريقة كتابة مختلفة. استخدم `while` عندما يعتمد شرط التوقف على شيء يتغيّر أثناء تشغيل البرنامج.

---

## 4. الدوال (Functions) — كتل قابلة لإعادة الاستخدام

الدالة هي كتلة كود لها اسم. تكتبها مرة واحدة، وتستخدمها عدة مرات.

```javascript
function رحّب(الاسم) {
    console.log("مرحبًا، " + الاسم + "!");
}

رحّب("Ali");
رحّب("Fatima");
رحّب("Jonas");
```

تتوقّع الدالة `رحّب` **معاملًا (parameter)** — `الاسم`.
في كل مرة تستدعي فيها الدالة، تُمرّر قيمة مختلفة.

**دوال تُعيد قيمة:**

```javascript
function مربع(رقم) {
    return رقم * رقم;
}

let النتيجة = مربع(4);
console.log(النتيجة);
```

`return` تُعيد قيمة إلى الوراء. يمكنك حفظها أو استخدامها مباشرة.

## 5. كل شيء معًا — برنامج مصغّر

```javascript
function قيّم(الدرجة) {
    if (الدرجة >= 90) {
        return "ممتاز";
    } else if (الدرجة >= 70) {
        return "جيد";
    } else if (الدرجة >= 55) {
        return "مقبول";
    } else {
        return "راسب";
    }
}

let الدرجات = [88, 42, 95, 67, 55];

for (let i = 0; i < الدرجات.length; i++) {
    let التقييم = قيّم(الدرجات[i]);
    console.log("الدرجة " + الدرجات[i] + ": " + التقييم);
}
```

انسخ هذا في الطرفية. راقب ما يحدث.
ثم غيّر إحدى الدرجات ونفّذه مجددًا.

هذا برنامج حقيقي: له مدخلات، ومعالجة، ومخرجات.

## 6. تمارين

جرّب هذه التمارين في طرفية المتصفح:

**التمرين 1:** اكتب دالة `هل_زوجي` تُعيد `true` إذا كان الرقم زوجيًا، و`false` إذا كان فرديًا. اختبرها بالأرقام 4، 7، 12، و9.

**التمرين 2:** اكتب حلقة تطبع جدول ضرب 3 (3، 6، 9، ... حتى 30 ضمنًا).

**التمرين 3:** أنشئ قائمة بخمسة أسماء. مرّ عبر القائمة واطبع كل اسم برسالة "مرحبًا بك، [الاسم]!".

*تلميح: استخدم `let الأسماء = ["اسم1", "اسم2", ...]` لإنشاء قائمة (array).*
