# الوحدة 5 — العمل محليًا

لقد رأيت Git، وشعرت به، ورسمته.
الآن سوف تقوم به فعليًا. في الطرفية (terminal)، على مستودع حقيقي.

---

## التحضير: التثبيت والإعداد

**ثبّت Git**
- Windows: [git-scm.com/download/win](https://git-scm.com/download/win)
- Mac: افتح الطرفية، واكتب `git --version` (يُثبَّت تلقائيًا أو يعطيك تعليمات)
- Linux: `sudo apt install git`

**اضبط اسمك وبريدك الإلكتروني** (يظهران في كل commit تقوم به):

```bash
git config --global user.name "اسمك"
git config --global user.email "بريدك@email.com"
```

تحقق من إعداداتك:

```bash
git config --list
```

---

## مستودع التمرين

في مسار التعلم هذا، نستخدم مستودعًا مخصصًا للتمرين:

**`git-garden-playground`**

سيعطيك معلمك الرابط الدقيق (URL).
يبدأ بـ `https://github.com/...`

هذا المستودع مخصص خصيصًا للتمرين — لا يمكنك إتلاف أي شيء فيه.

---

## الخطوة 1: الاستنساخ (Clone)

الاستنساخ يعني تنزيل مستودع إلى جهاز الكمبيوتر الخاص بك.

```bash
git clone https://github.com/...url.../git-garden-playground
```

بعد الاستنساخ:

```bash
cd git-garden-playground
ls
```

سترى ملفات المستودع. وستجد مجلدًا مخفيًا اسمه `.git` — إنه آلة الزمن.

---

## الخطوة 2: عرض الحالة

`git status` هو بوصلتك. استخدمه كثيرًا.

```bash
git status
```

سترى في أي فرع أنت، وما إذا كانت هناك ملفات قد تغيّرت.

---

## الخطوة 3: إجراء تغيير

افتح المجلد في محرر النصوص الخاص بك (أو استخدم الطرفية).
أنشئ ملفًا جديدًا داخل مجلد `deelnemers/`:

```bash
mkdir -p deelnemers
echo "Naam: [اسمك]" > deelnemers/[اسمك].txt
```

ثم تحقق من الحالة:

```bash
git status
```

يُبلغك Git بأن الملف الجديد "غير متتبَّع" (untracked) — إنه موجود، لكن Git لا يتتبعه بعد.

---

## الخطوة 4: التهيئة (Staging)

التهيئة (staging) تعني أن تقول: "أريد تضمين هذا الملف في الـ commit التالي."

```bash
git add deelnemers/[اسمك].txt
```

أو أضِف كل شيء دفعة واحدة:

```bash
git add .
```

تحقق من الحالة مجددًا. أصبح الملف الآن في "منطقة التهيئة" (staging area) — جاهز لعمل commit له.

![سير العمل: دليل العمل ← منطقة التهيئة ← المستودع](images/werkstroom.png)

---

## الخطوة 5: عمل commit

الآن ستُنشئ اللقطة الزمنية.

```bash
git commit -m "إضافة [اسمك] إلى قائمة المشاركين"
```

رسالة commit جيدة:
- تبدأ بفعل: "أضِف"، "أصلِح"، "حدِّث"، "احذف"
- تصف *ماذا* تغيّر، وليس *كيف*
- قصيرة (بحد أقصى نحو 72 حرفًا)

---

## الخطوة 6: عرض السجل التاريخي

```bash
git log
```

سترى جميع الالتزامات (commits): الـ hash، المؤلف، التاريخ، الرسالة.

لعرض موجز ومختصر:

```bash
git log --oneline
```

لعرض بصري يشمل الفروع:

```bash
git log --oneline --graph --all
```

---

## الخطوة 7: عرض الفروقات

هل تريد رؤية ما تغيّر قبل عمل commit؟

```bash
git diff
```

بعد التهيئة (staging)، ولكن قبل الـ commit:

```bash
git diff --staged
```

---

## ملخص: سير العمل اليومي

```
[إجراء تغيير]
      ↓
git add .
      ↓
git commit -m "..."
      ↓
git push   (سيأتي في الوحدة 6)
```

كرّر هذا النمط عشرات المرات يوميًا.
سيصبح ذلك تلقائيًا بمرور الوقت.
