# モジュール5 — ローカルで作業する

これまで、Gitを見て、感じて、そして描いてきました。
次はいよいよ、実際にやってみる番です。ターミナルで、本物のリポジトリを使って。

---

## 準備：インストールと設定

**Gitをインストールする**
- Windows：[git-scm.com/download/win](https://git-scm.com/download/win)
- Mac：ターミナルを開き、`git --version` と入力する（自動でインストールされるか、案内が表示されます）
- Linux：`sudo apt install git`

**名前とメールアドレスを設定する**（これは、あなたが作るすべてのコミットに記録されます）：

```bash
git config --global user.name "あなたの名前"
git config --global user.email "your@email.com"
```

設定内容を確認します：

```bash
git config --list
```

---

## 練習用リポジトリ

このカリキュラムでは、専用の練習用リポジトリを使います：

**`git-garden-playground`**

正確なURLは講師から教えてもらいます。
URLは `https://github.com/...` から始まります。

このリポジトリは練習専用です——何をしても壊れる心配はありません。

---

## ステップ1：クローン（Clone）

クローンとは、リポジトリを自分のコンピューターにダウンロードすることです。

```bash
git clone https://github.com/...url.../git-garden-playground
```

クローンが終わったら：

```bash
cd git-garden-playground
ls
```

リポジトリのファイルが見えるはずです。そして、隠しフォルダの`.git`もあります——これがタイムマシンです。

---

## ステップ2：状態を確認する

`git status` はあなたのコンパスです。頻繁に使いましょう。

```bash
git status
```

今どのブランチにいるか、そして変更されたファイルがあるかどうかがわかります。

---

## ステップ3：変更を加える

エディタでフォルダを開いてください（またはターミナルを使ってください）。
`deelnemers/` フォルダの中に新しいファイルを作成します：

```bash
mkdir -p deelnemers
echo "Naam: [あなたの名前]" > deelnemers/[あなたの名前].txt
```

その後、状態を確認します：

```bash
git status
```

Gitはこの新しいファイルを「untracked（追跡されていない）」と報告します——ファイルは存在していますが、Gitはまだそれを追跡していません。

---

## ステップ4：ステージング

ステージングとは、「このファイルを次のコミットに含めたい」と伝えることです。

```bash
git add deelnemers/[あなたの名前].txt
```

または、すべてを一度に追加します：

```bash
git add .
```

もう一度状態を確認してみましょう。ファイルは今、「ステージングエリア」に入っています——コミットの準備ができた状態です。

![ワークフロー：作業ディレクトリ → ステージングエリア → リポジトリ](images/werkstroom.png)

---

## ステップ5：コミットする

いよいよ、スナップショットを作成します。

```bash
git commit -m "参加者リストに[あなたの名前]を追加"
```

良いコミットメッセージとは：
- 動詞から始まる：「追加」「修正」「更新」「削除」
- *何が*変わったかを説明し、*どうやって*変えたかは説明しない
- 短い（最大でも約72文字程度）

---

## ステップ6：履歴を確認する

```bash
git log
```

すべてのコミット——ハッシュ、作者、日付、メッセージ——が表示されます。

コンパクトに一覧表示したい場合：

```bash
git log --oneline
```

ブランチを含めて視覚的に表示したい場合：

```bash
git log --oneline --graph --all
```

---

## ステップ7：差分を確認する

コミットする前に、何が変わったのかを見たいですか？

```bash
git diff
```

ステージング後、コミット前の差分を見るには：

```bash
git diff --staged
```

---

## まとめ：日々のワークフロー

```
[変更を加える]
      ↓
git add .
      ↓
git commit -m "..."
      ↓
git push   （モジュール6で学びます）
```

このパターンを、1日に何十回も繰り返します。
そのうち自然と、体に染みついていくはずです。
